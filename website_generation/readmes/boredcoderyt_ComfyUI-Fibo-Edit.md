# ComfyUI-Fibo-Edit

ComfyUI custom node for [Fibo Edit](https://github.com/Bria-AI/Fibo-Edit) image model.

---

## Basic Workflow

- **Example workflow**: [examples/workflow.json](examples/workflow.json)

![workflow.png](examples/workflow.png)

## Installation

- Download or git clone this repository into the `ComfyUI\custom_nodes\` directory and run:

```python
pip install -r requirements.txt
```

## Download Models

- Full Precision - [briaai/Fibo-Edit](https://huggingface.co/briaai/Fibo-Edit)
- 4-Bit Quant - [boredcoder/Fibo-Edit-4bit](https://huggingface.co/boredcoder/Fibo-Edit-4bit)
- 8-Bit Quant - [boredcoder/Fibo-Edit-8bit](https://huggingface.co/boredcoder/Fibo-Edit-8bit)
