# ComfyUI KMCDev Image Filter Adjustments

## Description

This is a plugin for ComfyUI that allows you to adjust the brightness, contrast, saturation, and sharpness of an image. It is the Simple Image Filter from [WAS Node Suite](https://github.com/WASasquatch/was-node-suite-comfyui) but does not require all the additional packages and dependencies to be installed to support the 200+ nodes shipped with the WAS Node Suite.
