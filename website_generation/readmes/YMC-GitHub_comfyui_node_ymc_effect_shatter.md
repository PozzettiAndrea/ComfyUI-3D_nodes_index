## Install

```bash
# cd to comfyui/custom_nodes
git clone https://github.com/ymc-github/comfyui_node_ymc_effect_shatter
```

- **deps will be installed automatically** if requirements in requirements.txt not installed when comfyui up

## Usage

- you can find it in right mouse menu : `ymc/image/effect/shatter`
