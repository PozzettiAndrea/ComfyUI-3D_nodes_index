# ComfyUI Photoreal Prompt Builder — NSFW Module

Optional NSFW content expansion for [ComfyUI-Photoreal-Prompt-Builder](https://github.com/artokun/ComfyUI-Photoreal-Prompt-Builder).

This module adds explicit pose, action, and group action expansions plus corresponding list nodes for batch generation.

## Contents

- **NSFW pose expansions** — 31 explicit pose descriptions mapped from short UI labels
- **NSFW action expansions** — 32 solo action descriptions
- **NSFW group action expansions** — 35 couples/partner action descriptions
- **List nodes** — NSFW Action List, NSFW Group Action List, NSFW Pose List (for XY Plot Queue)

## Installation

This module is installed automatically by the main prompt builder when NSFW is enabled in `config.json`. See the [main repo](https://github.com/artokun/ComfyUI-Photoreal-Prompt-Builder#nsfw-module) for setup instructions.
