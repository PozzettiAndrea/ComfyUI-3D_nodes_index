# Rabbit-Camera-Perspective
An intuitive prompt previewer ComfyUI node for use with Fal‘s Multi-View LoRA.

Why use this? 

Because it offers:

Better suitability for portraits: Specifically optimized for human subjects.

Intuitive visualization: Provides a clearer view and real-time prompt previews.

Seamless automation: 

Automatically copies the prompt when you drag the "rabbit" 
or 
click the button, while also providing a string output for direct connection to your prompt area.
