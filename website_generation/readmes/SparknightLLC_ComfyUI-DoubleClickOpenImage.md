# ComfyUI-DoubleClickOpenImage

A simple extension for [ComfyUI](https://github.com/comfyanonymous/ComfyUI) that allows you to double-click on the thumbnail of a node to open the full-size image in a new tab. Works with nodes such as `Preview Image` and `Load Image`.

Thank you to [ComfyUI-ImageGallery-ED](https://github.com/NyaamZ/ComfyUI-ImageGallery-ED), the code of which was helpful in figuring out how to bind the double-click event. It's a great extension if you want a built-in image viewer instead.
